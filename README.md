- 서비스 스펙: [`spec.md`](spec.md)
- 디자인 시스템: [`DESIGN.md`](DESIGN.md) · CSS 토큰 [`design/tokens.css`](https://github.com/ofseo03/Eodiro/blob/design/design/tokens.css) · 미리보기 [`design/preview.html`](https://github.com/ofseo03/Eodiro/blob/design/design/preview.html) (`design/` 파일은 `design` 브랜치에서 관리)
